<h2 align="center">🚀 精选项目</h2>

### 🤖 [xiaobao-ai-agent](https://github.com/KE-1027/xiaobao-ai-agent) — 政务 AI 助手

基于 RAG + LangGraph 的政务办事问答系统，覆盖 3145 个事项、12 个部门。

- 🧭 单 Agent 内部 9 节点流水线（意图分类 → 情景分析 → 信息充分性判断 → 策略决策 → 追问澄清 / 查询改写 → 混合检索 → 生成回答 → 反思审查）
- 🔍 混合检索：FAISS + BM25 + bge-reranker-v2-m3 + HyDE
- 🧠 三层记忆 + 用户画像
- 📊 LLM-as-Judge 四维评测：检索 MRR 0.89、生成质量 4.51/5、安全防御 94.4%、多轮 91.7%
